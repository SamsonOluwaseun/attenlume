# P1-21 report: export service

Branch: `phase-1/P1-21-export` (from main a4ec681). Builder: Claude Code (Opus 5.5). Decision record: ADR-040.

## What was built

- **Safe paths (FR-EXP-07)**, `lib/data/filesystem/safe_export_paths.dart`: ASCII slugs with common accents transliterated, Windows device names (`CON`, `NUL`, `COM1`, `LPT9`, with or without an extension) changed, no leading or trailing dots, dashes or spaces, folders capped at 60 characters, file names at 80, every path including the root folder under 180 characters, clashes suffixed `-2`, `-3` and compared case-insensitively.
- **Streaming writer (FR-EXP-02, 04, 05, 06)**, `lib/data/filesystem/export_writer.dart`: writes a plan of file copies, trimmed copies and generated text into `<name>.partial` (a folder, or a stored ZIP under one `<name>/` folder), writes `checksums.sha256`, then renames. On failure or cancel it deletes only the partial output and the job's temp folder. In the app it runs on a background isolate.
- **ExportService (FR-EXP-01, 03, 05, 10)**, `lib/domain/services/export_service.dart` and `export_documents.dart`: scopes (whole conference, selected activities, one day in the conference timezone) crossed with content (everything, audio only, photos only, notes and details only); audio as originals, trimmed copies via `Mp4SampleTrimmer`, or originals plus `cuts.json`; destination and temp-space preflight; an `export_jobs` row per run; the private switch; `activity.json`, `notes.md`, `bookmarks.csv` and a basic `conference.json`; the `ExportContributor` extension point for P1-22.
- **Export sheet**, `lib/features/export/export_sheet.dart` and `export_providers.dart`: opened from "Export conference" (conference home app bar) and "Export this activity" (activity details). Windows asks for a folder; Android and iOS use `<app documents>/exports/`. Shows size, free space, shortfall, progress with Cancel, and the saved location with "Copy location".
- **Shared code:** `segmentTrimChanges` extracted from `PermanentTrimService.plan` (behaviour unchanged, its tests pass); `copyFileHashing` and `hashFileSha256` in `folder_export.dart` made public.

## Review fixes (second commit round)

- **[P1] Privacy leak in multi-paragraph private thoughts (FR-EXP-10).** The quick-thought sheet marked only the first paragraph of a private thought, so the rest was exported with private items off. Fixed at the source: `formatQuickThought` in the new `lib/domain/services/private_notes.dart` wraps a private thought in `**[Private reflection]**` ... `**[End of private reflection]**`, and the quick-thought sheet uses it. `stripPrivateReflections` (moved to the same file) removes the whole block. Old-format notes (no end marker): the marked paragraph and everything after it, up to the next private or quick-thought marker or the end of the notes, are removed. This can drop public text typed after an old private thought, but never exports private text (ADR-040 item 9).
- **[P2] activity.json disagreed with checksums for trimmed copies (FR-EXP-03, FR-EXP-06).** `activity.json` is now generated while writing, after the activity's audio, from the facts of the files actually written (`GeneratedTextExportSource`). Exported segments report the written file's `bytes` and `sha256`; trimmed copies also report their own `duration_ms`, `trimmed: true`, `kept_ranges_ms` and the recording's values under `source_*` (ADR-040 item 7). `ExportedFile` gained an optional `durationMs`.

## Open questions

1. **Reaching phone exports.** Android's app documents folder is private and iOS does not show it in Files (`UIFileSharingEnabled` is not set). `share_plus` is not a dependency, so there is no share sheet. Suggest adding `share_plus` (planned in BUILD_GUIDE 9.1) or a save dialog in P1-22 or P1-27.
2. **Contact name and details** are left out of `activity.json` (other people's personal data). Owner to decide whether they go in, perhaps only with the private switch on.
3. **Private reflections inside notes** are found by the start and end markers and the "Private thought" bookmark label that the quick-thought sheet writes. A user who edits the start marker out of the notes makes that text public, and old-format notes may lose public text after a private thought (see Review fixes). A proper flag (a column or a separate private-notes field) would be sturdier.
4. **Compressed copy for AI upload** (FR-EXP-03 optional) is deferred: no encoder in the app.
5. **Kept originals** can be exported (`includeKeptOriginals`) but the sheet has no switch for it yet.
