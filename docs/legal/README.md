This folder holds the source of the published page:

- `Images/`: the logos and app icon the page shows. The icon here is the cleaned one (P1-56); on 2 November 2026 the live site still showed the earlier icon, so upload `Images/attenlume-app-icon.png` when next updating the page.

The page is hosted on the Samlytics Data Services website, in `public_html/attenlume-policy/`. To change it, edit the file here, have the owner review it, then upload the page and its `Images` folder to that folder. Contact: contactus@samlytics.co.uk.
